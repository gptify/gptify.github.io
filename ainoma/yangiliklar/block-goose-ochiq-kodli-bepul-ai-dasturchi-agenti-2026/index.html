Block ochiq kodli «goose» AI agentini chiqardi: Claude code uchun bepul muqobil

Square va Cash App egasi bo‘lgan Block kompaniyasi dasturchilar uchun oylik $200 gacha turadigan Claude Code kabi tizimlarga raqobatchi bo‘lgan bepul va ochiq kodli Goose avtonom agentini taqdim etdi.

Qisqacha mazmuni (Executive Summary)
  • Goose agenti terminal va operatsion tizim darajasida mustaqil ishlaydi, testlarni o‘tkazadi hamda refaktoring vazifalarini to‘liq bajaradi.
  • Istalgan LLM (Claude, GPT, Gemini yoki lokal Ollama) bilan ishlaydi hamda Anthropic ishlab chiqqan ochiq Model Context Protocol (MCP) standartini to‘liq qo‘llab-quvvatlaydi.
  • Linux Foundation qoshidagi Agentic AI Foundation boshqaruviga topshirildi va Apache 2.0 litsenziyasi ostida har qanday korxona uchun bepul taqdim etilmoqda.

Nima bo‘ldi?

Square va Cash App ekotizimlarini birlashtirgan Block kompaniyasi dasturchilar uchun mo‘ljallangan to‘liq avtonom va ochiq kodli Goose sun’iy intellekt agentini taqdim etdi. So‘nggi paytlarda oylik obuna narxi $200 gacha yetgan Claude Code kabi tijoriy dasturchi vositalariga qarshi ishlab chiqilgan ushbu tizim Linux Foundation qoshidagi Agentic AI Foundation (AAIF) boshqaruviga topshirildi.

Goose oddiy kod to‘ldirish (autocompletion) vositalaridan farq qilib, terminal va kompyuter muhitida to‘liq avtonom harakatlanadi. U dasturiy ta’minot testlarini ishga tushirish, repozitoriylarni klonlash, kutubxonalar migratsiyasini amalga oshirish va murakkab sintaksis xatolarini mustaqil tahrirlash qobiliyatiga ega. Siz ushbu agentni terminal, maxsus desktop ilova yoki dasturchilar uchun SDK orqali ishlatishingiz mumkin.

Nega muhim?

Bugungi kunda xususiy sun’iy intellekt modellari foydalanuvchini faqat bitta provayderga (vendor lock-in) bog‘lab qo‘ymoqda. Goose esa to‘liq neytral platforma bo‘lib, dasturchilarga xohlagan til modelini tanlash erkinligini beradi: Claude 3.7, GPT-4o, Gemini 1.5/2.0, DeepSeek yoki hatto Ollama orqali lokal kompyuterda ishlovchi ochiq modellarni ulash mumkin.

Shuningdek, Goose Anthropic tomonidan ilgari surilgan ochiq Model Context Protocol (MCP) standartini to‘liq qo‘llab-quvvatlaydi. Bu orqali siz agentni GitHub, Jira, PostgreSQL ma’lumotlar bazalari va maxsus ichki API’lar bilan bir zumda sinxronlashtirishingiz mumkin bo‘ladi.

👤 Muhandislar va dasturchilar uchun
  • To‘liq erkinlik: Apache 2.0 litsenziyasi ostida mutlaqo bepul foydalanish va kodini moslashtirish.
  • Provayder erkinligi: Istalgan API kalitini ulash yoki oflayn tarzda lokal modellar bilan ishlash.
  • MCP kengaytmalari: Mavjud vositalar va ma’lumotlar bazalariga standart protokollar orqali ulanish.
🏢 Startaplar va IT kompaniyalar uchun
  • Dasturchi litsenziyalari tejami: Har bir xodim uchun oyiga $100–$200 to‘lash o‘rniga ochiq kodli agentdan foydalanish.
  • Ma’lumotlar maxfiyligi: Maxfiy kod bazalarini uchinchi tomon serverlariga yubormasdan lokal serverda ishlatish.
  • Agentik avtomatlashtirish: Yangi dasturchilarni loyihaga jalb qilish va kod bazasini o‘rganish vaqtini qisqartirish.
Bu O‘zbekiston dasturchilar jamoasi uchun nimani anglatadi?

Mahalliy startaplar va autsorsing kompaniyalari uchun yuqori oylik AI obuna xarajatlari jiddiy to‘siq bo‘lib kelayotgan edi. Goose orqali mahalliy dasturchilar jahon darajasidagi avtonom agentlik imkoniyatlaridan tekinga foydalanishlari va o‘z loyihalariga sun’iy intellektni xavfsiz tatbiq etishlari mumkin bo‘ladi.

🎯 Siz uchun amaliy tavsiyalar
  1. Goose repozitoriysini tekshiring: GitHub orqali rasmiy loyihani ko‘rib chiqing va CLI vositasini o‘rnatib sinab ko‘ring.
  2. Lokal LLM bilan sinang: Ollama orqali ochiq modellarni ulab, maxfiy loyihalaringizda xavfsiz test o‘tkazing.
  3. Jamoangizga MCP vositalarini tanishtiring: Ma’lumotlar bazalari va kod bazangizni agent bilan birlashtiring.
